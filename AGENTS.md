Untuk setiap permintaan yang melibatkan penulisan atau perubahan kode, selalu ikuti alur ini:
1. Delegasikan penulisan kode ke agent "coder"
2. Setelah coder selesai, delegasikan hasilnya ke agent "reviewer"
3. Setelah reviewer menyetujui, delegasikan ke agent "qa" untuk testing
4. Laporkan ringkasan hasil ke pengguna

Jangan lewati salah satu tahap ini kecuali pengguna secara eksplisit minta cara cepat.
